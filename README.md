# DevPulse AI

DevPulse AI is a modern web application built with [Next.js](https://nextjs.org/), [TypeScript](https://www.typescriptlang.org/), and [Tailwind CSS](https://tailwindcss.com/). Live deployment is hosted on [Vercel](https://devpulseai-one.vercel.app).

---

## 🚀 Live Demo

Check out the live application here: [devpulseai-one.vercel.app](https://devpulseai-one.vercel.app)

---

## ✨ Features

- **Next.js App Router:** Optimized performance with server components and seamless routing.
- **TypeScript:** Type-safe architecture across the application.
- **Tailwind CSS & PostCSS:** Fully responsive, modern UI design system.
- **Environment Configuration:** Clean separation of secrets using environment variables.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), PostCSS
- **Deployment:** [Vercel](https://vercel.com/)
